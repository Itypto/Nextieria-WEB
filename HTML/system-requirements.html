Nextieria System Requirements

Windows (PC)

Minimum Requirements:

  • OS: Windows 8/10 64-bit
  • CPU: Intel Core i3-3225 3.3 GHz
  • RAM: 4 GB
  • GPU: Intel HD 4000 / Intel Iris Pro 5200

Recommended Requirements:

  • OS: Windows 10/11 64-bit
  • CPU: Core i5-7300U / Ryzen 3 3300X
  • RAM: 8 GB
  • GPU: Nvidia GTX 660 / AMD Radeon HD 7870

iOS / iPadOS

  • OS: iOS 11.0 or higher
  • Device: iPhone 6S / SE or newer
  • RAM: 2 GB minimum

Android

  • OS: Android 8.0 or higher (64-bit)
  • RAM: 3 GB minimum
