About Nextieria

Nextieria is an OGFN project focused on bringing back older Fortnite seasons and allowing players to experience versions of the game that are no longer officially available.

The project originally started in June 2025 under the name Fynox. After some issues involving another project, we decided to rebrand and continue the project as Nextieria in March 2026.

Since then, Nextieria has grown into much more than just a way to launch an older Fortnite build. We continue to develop our own backend systems, redirects, launcher features, matchmaking systems, website, and gameserver features while improving the overall experience for players.

Nextieria currently hosts Fortnite Season 6 | v6.31 under the slogan "Darkness Rises."

Development & Attribution

Nextieria contains both original code and code based on existing open-source projects. We do not claim ownership of code or projects originally created by other developers.

Open-source projects have played an important role in Nextieria's development. In some cases, an existing project provided a useful starting point that we could learn from, modify, and expand instead of rebuilding the same system immediately from scratch.

When a Nextieria component is based on another project, we try to clearly state where it came from and give credit to the original developer. At the same time, many parts of Nextieria are now developed specifically for the project and continue to move toward our own implementations.

This includes backend systems, matchmaking work, redirects, gameserver development, the website, and other internal services. Our goal is to keep learning from existing projects while gradually becoming more independent where it makes sense.

Our approach: if a Nextieria component is based on another project, the original project receives credit. Changes, new features, and systems developed specifically for Nextieria are maintained by the Nextieria team. Component = GS, Backend, Launcher, Redirects etc

Safety

Nextieria takes user safety and security seriously. Official Nextieria software is not intentionally designed to contain malware, steal credentials, collect sensitive information, or perform malicious actions on a user's device.

Some parts of Nextieria use techniques that are uncommon in normal desktop software. For example, redirects may use DLL injection or request redirection so that an older Fortnite client connects to Nextieria's services instead of the original services it was designed to use.

Because similar techniques can also be used by malicious programs, some antivirus software may detect certain Nextieria files as suspicious. In some cases, these detections may be false positives caused by the way the redirect or launcher works.

Do not automatically trust a file simply because it has the Nextieria name. Always make sure it was downloaded from an official Nextieria source.

Nextieria will never ask for your Epic Games password, Discord token, browser cookies, or other sensitive account credentials.

Always download Nextieria from the official Nextieria website or our official Discord server .

We cannot guarantee the safety of files downloaded from unofficial mirrors, modified builds, or third-party reuploads.

Backend Info

The Nextieria backend is primarily developed and maintained by Itypto. It handles the core services needed for older Fortnite clients to communicate with Nextieria, including account systems, game services, matchmaking integration, and other backend functionality.

The project originally started with Lawin V2 as its foundation. During the earlier stages of development, Lawin V2 provided a useful starting point while the backend was still being built and expanded.

Beginning in April 2026, the backend went through a major overhaul. Large parts of the original structure were rewritten, replaced, reorganized, or removed entirely, while new systems were developed specifically for Nextieria.

Since then, development has continued around Nextieria's own architecture and requirements. The current backend no longer at all resembles the original Lawin V2 base.

Lawin V2 remains an important part of the project's history and is credited for providing the original foundation, but the majority of the current backend has since been developed specifically for Nextieria and now the backend is 99% original code written by the Nextieria team.

The backend is mainly written in JavaScript. A new matchmaking system written in Go is also currently in development.

As Nextieria continues to grow, the backend will continue to be improved, rewritten where necessary, and expanded with new systems developed specifically for the project.

Gameserver Info

The current Nextieria Lategame gameserver is developed and maintained by Itypto and is built upon the foundation of Erbium , a free and open-source Fortnite gameserver created by plooshi.

Erbium provides the original gameserver base. Since using it, Nextieria's version has been heavily modified and expanded to work with our own backend, systems, and project-specific features.

We fully credit plooshi for the original Erbium project and do not claim the original Erbium source code as our own. The changes and additional systems made specifically for Nextieria are developed and maintained as part of our project.

A new gameserver built specifically for Nextieria is also currently in development. The goal is to eventually give us greater control over how the gameserver works and reduce our reliance on an existing gameserver base.

Season 6 | v6.31

Nextieria currently hosts Fortnite Season 6, version 6.31, under the slogan "Darkness Rises."

Season 6 is known for its darker and more mysterious atmosphere, with the Cube storyline, floating island, corrupted areas, and the Halloween-themed changes that came with the season.

We chose Season 6 because we wanted to bring back that atmosphere and give players a way to experience the season again as closely as possible.

Our current focus is improving the Season 6 experience rather than constantly switching versions. Other seasons may be considered in the future as Nextieria continues to develop.

Vision

Why was Nextieria created?

I've always been interested in backend development and understanding how things work behind the scenes.

After discovering the OGFN community, that interest became something I wanted to learn more about. Working on Nextieria has given me the chance to learn more about APIs, networking, matchmaking, redirects, gameservers, authentication, and how different services work together.

Nextieria originally started as a learning project and as a way to let people experience older Fortnite seasons again. Over time, it has grown into a much larger project with its own backend systems, launcher, website, redirects, gameserver work, and other services.

One of the main goals for Nextieria is to continue becoming more independent by developing more of our own systems while still giving proper credit to the open-source projects that helped us get to where we are today.

The project is still actively being developed, and there is always more to improve. For us, that is one of the main reasons Nextieria exists: to keep learning, building, and improving the project over time.
